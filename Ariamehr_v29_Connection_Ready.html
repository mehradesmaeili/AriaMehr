گفت‌وگو با آریامهر

یادآوری: گفتگوها، کلمه‌ها و آموزش‌ها در حافظهٔ همین مرورگر و همین دستگاه ذخیره می‌شوند؛ پاک‌کردن داده‌های مرورگر یا استفاده از مرورگر دیگر ممکن است آن‌ها را حذف کند. برای نگهداری امن‌تر، از «پشتیبان‌گیری» استفاده کن.

آموزش سؤال و جواب جدید

سؤال و جواب را وارد کن تا آریامهر در گفت‌وگوهای بعدی هم از آن استفاده کند.

یاد دادن کلمه و ذخیرهٔ معنی

کلمه و معنی‌اش را وارد کن؛ آریامهر آن را در حافظهٔ همین مرورگر ذخیره می‌کند و بعداً می‌تواند معنی‌اش را بگوید.

حافظه و اطلاعات ذخیره‌شده

اتصال به هوش مصنوعی واقعی

پس از راه‌اندازی سرور امن، نشانی API گفت‌وگو را اینجا وارد کن. کلید API محرمانه را هرگز در این صفحه یا داخل APK نگذار.

وضعیت: هنوز متصل نیست؛ تا وقتی سرور واقعی تنظیم نشود، پاسخ‌ها آفلاین هستند.

سرور باید درخواست JSON شامل message و history را بپذیرد و پاسخ JSON با فیلد reply برگرداند. کلید محرمانه باید فقط روی سرور نگهداری شود.

اشتراک ویژهٔ آریامهر

طرح ماهانه

۱٬۰۰۰٬۰۰۰ تومان

مدت اشتراک: یک ماه

وضعیت: درگاه بانکی هنوز متصل نشده است.

مهم دربارهٔ پرداخت: این نسخه تا زمانی که سرور امن و درگاه معتبر راه‌اندازی و آزمایش نشوند، هیچ پولی دریافت نمی‌کند. برای دریافت واقعی پول باید درگاه معتبر و سرور امن برای تأیید تراکنش و فعال‌سازی اشتراک راه‌اندازی شود. سرور باید مبلغ را خودش تعیین کند و تراکنش را با API رسمی درگاه تأیید کند؛ بازگشت کاربر به برنامه به‌تنهایی اثبات پرداخت نیست. اطلاعات کارت بانکی یا رمز را داخل این فایل وارد نکن.
دربارهٔ نسخهٔ آفلاین: این نسخه پاسخ‌های روزمره و تشخیص عبارت‌های فارسی بیشتری دارد، عددهای فارسی را برای محاسبات ساده می‌خواند و از آموزش‌های ذخیره‌شده استفاده می‌کند. هنوز آفلاین است و به مدل بزرگ هوش مصنوعی متصل نیست؛ بنابراین ممکن است پاسخ بعضی سؤال‌ها را نداند.
